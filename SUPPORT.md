# Support

Start with the [README](./README.md), [configuration guide](./docs/configuration.md), and [CLI reference](./docs/cli.md).

For reproducible bugs, open a bug issue with the package/version, Node.js and pnpm versions, operating system, minimal configuration with secrets removed, exact command, error output, expected behavior, and actual behavior.

For usage questions, consult the documentation and open a question/support
issue if the answer is not covered. Open a feature issue for a concrete
proposal. Use the private vulnerability-reporting process in [SECURITY.md](./SECURITY.md)
for security issues. Never post GitHub tokens, credentials, or private
repository data.
