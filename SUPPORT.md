# Support

Start with the [README](./README.md), [configuration guide](./docs/configuration.md), and [CLI reference](./docs/cli.md).

For reproducible bugs, open an issue with the package/version, Node.js and pnpm versions, operating system, minimal configuration with secrets removed, exact command, error output, expected behavior, and actual behavior.

Use discussions for usage questions and feature proposals. Never post GitHub tokens or private repository data.
